# IBM Data Science Projects

This repository contains a curated set of data science projects and exercises completed as part of an IBM Data Science program and subsequently reorganized for portfolio presentation.

The work spans data collection, exploratory analysis, visualization, geospatial analysis, dashboarding, and machine learning using Python and Jupyter Notebooks.

---

## Featured Project

### 🚀 SpaceX Falcon 9 Landing Outcome Prediction
An end-to-end analytical project examining the factors associated with successful SpaceX Falcon 9 first-stage booster landings and developing a predictive model for landing outcomes.

📂 **Project folder:** `/spacex`  
📄 **Final report:** Available via an online viewer and as a downloadable PDF  
🧠 **Methods:** Exploratory Data Analysis (EDA), SQL analysis, geospatial mapping, dashboards, and machine learning

➡️ Start here: **[`/spacex`](./spacex)**
